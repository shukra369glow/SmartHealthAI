# SmartHealthAI 🩺🤖

## AI-Powered Health Assistant

SmartHealthAI is an AI-based health assistant that helps users get quick health-related guidance through natural language conversations. It uses Google's Gemini AI to provide simple, informative responses about symptoms, health concerns, and general wellness guidance.

## 🚀 Features

### 1. AI Health Assistant

* Users can ask health-related questions.
* Provides AI-generated responses using Gemini AI.
* Helps users understand symptoms and possible precautions.

### 2. Simple User Interface

* Clean and easy-to-use chat interface.
* Designed for quick interaction and accessibility.

### 3. AI-Powered Responses

* Uses Google's Gemini AI model for intelligent conversations.
* Provides personalized responses based on user queries.

## 🛠️ Technologies Used

* **Frontend:** React.js + Vite
* **Programming Language:** JavaScript
* **AI Model:** Google Gemini API
* **Styling:** CSS
* **Version Control:** Git & GitHub

## ⚙️ Installation & Setup

### Clone the repository

```bash
git clone https://github.com/shukra369glow/SmartHealthAI.git
```

### Navigate to project folder

```bash
cd SmartHealthAI
```

### Install dependencies

```bash
npm install
```

### Add Gemini API Key

Create a `.env` file in the project root:

```
VITE_GEMINI_API_KEY=your_api_key_here
```

### Run the application

```bash
npm run dev
```

The application will run locally at:

```
http://localhost:5173/
```
